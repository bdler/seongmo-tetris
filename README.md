# Seongmo Tetris

설치 없이 브라우저에서 바로 실행되는 HTML 테트리스입니다. `index.html` 파일 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## Google Apps Script로 배포하기

1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만듭니다.
2. 기본 `Code.gs` 내용을 이 저장소의 `Code.gs`로 바꿉니다.
3. 파일 추가(+) → **HTML**을 선택하고 이름을 `index`로 만든 뒤, `index.html` 내용을 붙여넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 액세스 권한을 정한 뒤 배포합니다.
5. 발급된 웹 앱 URL로 접속하면 게임이 실행됩니다.

게임 화면을 한 번 클릭(또는 시작하기 버튼)해야 키보드 입력이 들어갑니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 저니 (JOURNEY) | 10개 스테이지를 여행합니다. 10줄마다 다음 스테이지로 넘어가며 테마·음악·속도가 바뀝니다. 100줄을 지우면 완주! |
| 젠 (ZEN) | 게임오버 없이 편하게 즐깁니다. 판이 가득 차면 아래 8줄이 정리됩니다. 10줄마다 테마가 바뀝니다. |
| 디그 (DIG) | 바닥에 깔린 쓰레기 줄 10개를 최대한 빨리 파내는 타임어택입니다. |
| 스프린트 (40L) | 40줄을 가장 빨리 지우는 타임어택입니다. |
| 울트라 (2MIN) | 2분 동안 최고 점수에 도전합니다. 10줄마다 레벨이 올라 빨라집니다. |

### 존 (ZONE)

Tetris Effect의 존 시스템을 가져왔습니다. 줄을 지우면 존 게이지가 차고, 1/4 이상 차면 **E 키**(모바일은 ZONE 버튼)로 발동할 수 있습니다.
발동 중에는 블록이 저절로 떨어지지 않고, 지운 줄이 바닥에 하얗게 쌓였다가 시간이 끝나면 한꺼번에 터집니다. 8줄 이상이면 OCTORIS, 12줄 DODECATRIS, 16줄 DECAHEXATRIS…
(저니·젠 모드에서만 쓸 수 있습니다.)

스테이지 테마: 새벽 → 바다 → 숲 → 사막 → 벚꽃 → 노을 → 네온 도시 → 오로라 → 우주 → 태양

## 조작법

| 키 | 동작 |
| --- | --- |
| ← → | 좌우 이동 (길게 누르면 연속 이동) |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| C / Shift | 홀드 |
| E | 존 발동 |
| P / Esc | 일시정지 |
| M | 소리 켜기/끄기 |
| 1 ~ 5 | 메뉴에서 저니 / 젠 / 디그 / 스프린트 / 울트라 바로 시작 |
| Enter | 시작 / 다시 하기 |

모바일에서는 화면 아래의 터치 버튼으로 조작합니다.
설정 화면에서 P·M·Enter·Esc를 뺀 모든 키를 바꿀 수 있습니다(동작마다 2개까지). 키는 자판 위치로 인식해서 한글 입력 상태에서도 그대로 작동합니다.

## 기능

- SRS 회전 시스템과 월킥
- 7-bag 랜덤 생성, 다음 블록 5개 미리보기, 홀드
- 고스트 피스, 락 딜레이(이동/회전 시 최대 15회 초기화)
- 레벨이 오를수록 빨라지는 낙하 속도 (10줄마다 레벨 업)
- 점수: 싱글/더블/트리플/테트리스, T-스핀, 백투백, 콤보, 드롭 보너스
- 줄 삭제 파티클, 화면 흔들림, 하드 드롭 잔상, TETRIS·T-SPIN·PERFECT CLEAR 연출
- 스테이지별 배경 그라데이션, 블록 스타일, 배경 파티클(별·물방울·나뭇잎·꽃잎·눈 등)
- WebAudio로 만든 효과음과 스테이지별 배경음 (음원 파일 없음)
- READY → GO 카운트다운, 게임 종료 시 통계(블록/초, 테트리스·T-스핀 수, 최대 콤보·존)
- 설정: 이동 시작 지연(DAS)·연속 이동 간격(ARR)·소프트 드롭 속도, 고스트·격자·흔들림·배경 효과 켜기/끄기
- 메뉴의 블록 로고 애니메이션과 저니 지도(도달한 스테이지 표시)
- 블록 스킨 선택: 자동(스테이지별) / 입체 / 유리 / 둥근 / 단색 / 네온
- 모드별 최고 기록 브라우저 저장
- 온라인 순위표 (Apps Script로 배포했을 때)

글꼴은 Google Fonts(Black Han Sans, Chakra Petch, IBM Plex Sans KR)를 사용합니다. 인터넷이 안 되면 기본 글꼴로 표시됩니다.

## 온라인 순위표

Apps Script 웹 앱으로 배포하면 게임이 끝났을 때 이름을 넣고 **순위 등록**을 할 수 있고, 메뉴의 **순위표**에서 모드별 상위 10명을 볼 수 있습니다.

- 기록은 스크립트가 처음 저장할 때 내 Google 드라이브에 자동으로 만드는 스프레드시트 **"Seongmo Tetris 순위표"**의 `scores` 시트에 쌓입니다. 이미 있는 스프레드시트를 쓰려면 Apps Script **프로젝트 설정 → 스크립트 속성**에 `SHEET_ID`(스프레드시트 ID)를 넣으세요.
- `Code.gs`를 바꾼 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다. 처음 한 번은 스프레드시트 접근 권한 승인 창이 뜹니다.
- 웹 앱 설정은 **실행: 나(소유자)**, **액세스: 모든 사용자**(또는 조직 내 사용자)로 두면 다른 사람도 기록을 남길 수 있습니다.
- 점수는 브라우저에서 계산해 보내므로 마음먹으면 조작할 수 있습니다. 이상한 기록은 스프레드시트에서 해당 행을 지우면 순위표에서도 사라집니다.
- `index.html`을 파일로 그냥 열면 순위표 대신 이 기기의 내 최고 기록만 보입니다.
