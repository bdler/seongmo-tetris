# Seongmo Tetris

설치 없이 브라우저에서 바로 실행되는 HTML 테트리스입니다. `index.html` 파일 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## Google Apps Script로 배포하기

1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만듭니다.
2. 기본 `Code.gs` 내용을 이 저장소의 `Code.gs`로 바꿉니다.
3. 파일 추가(+) → **HTML**을 선택하고 이름을 `index`로 만든 뒤, `index.html` 내용을 붙여넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 액세스 권한을 정한 뒤 배포합니다.
5. 발급된 웹 앱 URL로 접속하면 게임이 실행됩니다.

게임 화면을 한 번 클릭(또는 시작하기 버튼)해야 키보드 입력이 들어갑니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 저니 (JOURNEY) | 10개 스테이지를 여행합니다. 10줄마다 다음 스테이지로 넘어가며 테마·음악·속도가 바뀝니다. 100줄을 지우면 완주! |
| 젠 (ZEN) | 게임오버 없이 편하게 즐깁니다. 판이 가득 차면 아래 8줄이 정리됩니다. 10줄마다 테마가 바뀝니다. |
| 디그 (DIG) | 바닥에 깔린 쓰레기 줄 10개를 최대한 빨리 파내는 타임어택입니다. |

스테이지 테마: 새벽 → 바다 → 숲 → 사막 → 벚꽃 → 노을 → 네온 도시 → 오로라 → 우주 → 태양

## 조작법

| 키 | 동작 |
| --- | --- |
| ← → | 좌우 이동 (길게 누르면 연속 이동) |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| M | 소리 켜기/끄기 |
| 1 / 2 / 3 | 메뉴에서 저니 / 젠 / 디그 바로 시작 |
| Enter | 시작 / 다시 하기 |

모바일에서는 화면 아래의 터치 버튼으로 조작합니다.

## 기능

- SRS 회전 시스템과 월킥
- 7-bag 랜덤 생성, 다음 블록 5개 미리보기, 홀드
- 고스트 피스, 락 딜레이(이동/회전 시 최대 15회 초기화)
- 레벨이 오를수록 빨라지는 낙하 속도 (10줄마다 레벨 업)
- 점수: 싱글/더블/트리플/테트리스, T-스핀, 백투백, 콤보, 드롭 보너스
- 줄 삭제 파티클, 화면 흔들림, 하드 드롭 잔상, TETRIS·T-SPIN·PERFECT CLEAR 연출
- 스테이지별 배경 그라데이션, 블록 스타일, 배경 파티클(별·물방울·나뭇잎·꽃잎·눈 등)
- WebAudio로 만든 효과음과 스테이지별 배경음 (음원 파일 없음)
- 모드별 최고 기록 브라우저 저장
